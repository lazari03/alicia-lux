# Alicia Lux commerce backend

Medusa v2 with PostgreSQL. See the repository [setup instructions](../../README.md) and [architecture](../../docs/architecture.md). The official starter conventions in `src/` are retained for future modules, workflows, API routes and subscribers.

`npm run dev` starts the development API and Admin. `npm run build` compiles both. `npm start` starts the compiled application under `.medusa/server`; inject environment variables or copy your local `.env` there before running it.
