# Alicia Lux storefront

Next.js App Router, React, TypeScript and Tailwind CSS, using the official Medusa storefront SDK and commerce components. See the repository [setup instructions](../../README.md), [architecture](../../docs/architecture.md) and [verification record](../../docs/verification.md).

`npm run dev` serves port 8000. `npm run typecheck` checks TypeScript. `npm run build` creates a production build, querying the configured Medusa API for product pages. `npm start` serves that build.
